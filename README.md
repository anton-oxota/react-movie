# 🎬 React Movie App

A sleek and modern **React** application that allows users to explore movies, view detailed information, and enjoy a fast, responsive UI — all built with **Vite** and deployed on **Netlify**.

---

## 📖 Description

The **React Movie App** is a single-page application designed to showcase movies using a smooth and minimal user experience.  
It demonstrates core front-end development practices such as component-based architecture, efficient state management, and responsive design — all powered by the latest **React** ecosystem.

---

## 🌐 Live Demo

https://ao-react-movie.netlify.app/

---

## ✨ Features

-   🎥 **Browse Movies** — Explore trending and popular films
-   🔍 **Search Functionality** — Quickly find movies by title
-   🧾 **Movie Details** — View synopsis, ratings, genres, and release dates
-   💾 **Favorites / Watchlist** — Save your favorite movies locally
-   ⚡ **Fast Performance** — Powered by **Vite** for ultra-quick builds and HMR
-   🖥 **Responsive Design** — Optimized for both desktop and mobile
-   ☁️ **Deployed on Netlify** — Seamless CI/CD and global CDN

---

## 🛠 Technologies Used

-   **Framework:** React 18+
-   **Bundler:** Vite
-   **Language:** JavaScript (ES6+)
-   **Tech Stack** React, TypeScript, TanStack Query, Redux
-   **Styling:** CSS Modules
-   **Deployment:** Netlify

---

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/anton-oxota/react-movie.git

# Navigate to the project directory
cd react-movie

# Install dependencies
npm install

# Run the development server
npm run dev

# Build the production version
npm run build
```
